Part 2: Tables & Figures

Making Tables

Option 1: Markdown table

| Name | Value |
|------|-------|
| A    | 10    |
| B    | 20    |

Option 2: From R code (better!)

```{r}
library(gt)

data %>%
  gt()
```

Better Tables with GT

```{r}
Salaries %>%
  group_by(sex) %>%
  summarise(avg_salary = mean(salary)) %>%
  gt() %>%
  fmt_currency(columns = avg_salary)
```

Creates a beautiful, formatted table!

Regression Tables

```{r}
library(modelsummary)

model <- lm(salary ~ sex, data = Salaries)

modelsummary(model, stars = TRUE)
```

Shows coefficients, standard errors, and statistics automatically!

Adding Captions

Add #| options at the top of chunk:

```{r}
#| label: tbl-summary
#| tbl-cap: "Average Salaries"

Salaries %>%
  group_by(sex) %>%
  summarise(avg_salary = mean(salary)) %>%
  gt()
```

Making Plots

```{r}
#| label: fig-scatter
#| fig-cap: "Salary vs Experience"

ggplot(Salaries, aes(x = yrs.service, y = salary)) +
  geom_point() +
  theme_minimal()
```

Part 3: Equations & References

Writing Equations

Inline: Use single $

The coefficient $\beta_1$ shows the effect.

Display: Use double $$

$$
y = \beta_0 + \beta_1 x + \epsilon
$$

Numbered Equations

Add \tag{} for numbers:

$$
salary_i = \beta_0 + \beta_1 sex_i + \epsilon_i \tag{1}
$$

Result: \[ salary_i = \beta_0 + \beta_1 sex_i + \epsilon_i \tag{1} \]

Common Math Symbols

$\alpha, \beta, \gamma$    # Greek letters
$x_i$                       # Subscript
$x^2$                       # Superscript
$\bar{x}$                   # Mean
$\hat{y}$                   # Predicted value

Cross-References

Reference tables: @tbl-name

See @tbl-summary for results.

Reference figures: @fig-name

As shown in @fig-scatter...

Reference sections: @sec-name

# Methods {#sec-methods}

See @sec-methods for details.

Multiple Output Formats

Change YAML to export to different formats:

format:
  html:
    toc: true
  pdf:
    toc: true
  docx:
    toc: true

Now you can render to HTML, PDF, or Word!

Common Issues

Problem: Code doesn’t run

Solution: Check for typos, load required packages

Problem: Table doesn’t show

Solution: Make sure you use gt() or similar

Problem: Reference doesn’t work

Solution: Check label starts with tbl- or fig-

Tips & Resources

Quick Tips

  1. Render often to catch errors early
  2. Use descriptive labels (tbl-results, not tbl-1)
  3. Always add captions to tables and figures
  4. Hide package loading messages with #| message: false
  5. Keep it simple at first!
