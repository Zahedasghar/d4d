Session 1: Getting Started

What is Quarto?

  • Next-generation scientific and technical publishing system
  • Works with R, Python, Julia, and Observable JS
  • Creates documents, presentations, websites, books, and more
  • One source → multiple outputs (HTML, PDF, Word, slides)
  • Open source and developed by Posit (formerly RStudio)

Think of it as: Markdown + Code + Output = Beautiful Documents

Why Quarto?

Advantages:

  • Reproducible research
  • Multiple output formats
  • Language agnostic
  • Active community
  • Easy to learn

Use Cases:

  • Research papers
  • Reports & dashboards
  • Presentations
  • Websites & blogs
  • Books & tutorials

Your First Quarto Document

File structure:

---
title: "My First Document"
author: "Your Name"
format: html
---

# Introduction

This is my first Quarto document!

## Section 1

Here's some text with **bold** and *italic*.

YAML Header

The YAML header controls document settings:

---
title: "Document Title"
author: "Author Name"
date: "2024-11-19"
format: 
  html:
    toc: true
    code-fold: true
    theme: cosmo
---

Pro Tip

YAML is indentation-sensitive! Use spaces, not tabs.

Working with Code Chunks

R example:

```{r}
# This is an R code chunk
x <- c(1, 2, 3, 4, 5)
mean(x)
```

Python example:

```{python}
# This is a Python code chunk
numbers = [1, 2, 3, 4, 5]
print(f"Mean: {sum(numbers)/len(numbers)}")
```

Code Chunk Options

Control how code appears:

```{r}
#| echo: false      # Hide code, show output
#| eval: true       # Run the code
#| warning: false   # Hide warnings
#| message: false   # Hide messages
#| fig-cap: "My Plot"

plot(cars)
```

Note

Use #| for chunk options (recommended) or {r, echo=FALSE} style

Inline Code

Mix code with text:

The mean of our data is `r mean(c(1,2,3,4,5))`.

We analyzed `python len(data)` observations.

Output:

The mean of our data is 3.

We analyzed 150 observations.

Creating Tables

Markdown tables:

| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| A        | B        | C        |
| 1        | 2        | 3        |

From code:

```{r}

#| tbl-cap: "Sample Data"

library(knitr)
kable(head(mtcars, 5))
```

Images and Figures

Markdown syntax:

![Caption text](path/to/image.png)

![Logo](https://quarto.org/quarto.png){width=50%}

From code:

```{r}
#| label: fig-plot
#| fig-cap: "Scatter plot of cars data"

plot(cars)
```

Cross-References

Reference figures, tables, and sections:

See @fig-plot for the visualization.

As shown in @tbl-example, the data includes...

More details in @sec-methods.

# Methods {#sec-methods}

Important

Labels must start with fig-, tbl-, or sec- for auto-numbering

Session 2: Advanced Features

Callout Blocks

Create attention-grabbing blocks:

::: {.callout-note}
This is a note callout.
:::

::: {.callout-warning}
This is a warning!
:::

::: {.callout-tip}
## Custom Title
Pro tips go here!
:::

Types: note, warning, important, tip, caution

Divs and Spans

Divs for blocks:

::: {.class-name}
Content here
:::

::: {style="background-color: lightblue; padding: 10px;"}
Custom styled content
:::

Spans for inline:

This is [special text]{.highlight}.

This is [red text]{style="color: red;"}.

Layouts and Columns

Two-column layout:

::: {.columns}
::: {.column width="40%"}
Left column content
:::

::: {.column width="60%"}

:::
:::

Multiple panels:

::: {layout-ncol=2}

![Image 2](img2.png)
:::

Tabsets

Create tabbed content:

Multiple Output Formats

Single source, multiple formats:

---
title: "Flexible Document"
format:
  html:
    toc: true
    theme: cosmo
  pdf:
    documentclass: article
  docx:
    reference-doc: template.docx
---

Render specific format: quarto render doc.qmd --to pdf

Parameterized Reports

Add parameters:

---
title: "Sales Report"
params:
  region: "North"
  year: 2024
---

Use in code:

```{r}
region <- params$region
year <- params$year

# Filter data based on parameters
filtered_data <- data %>% 
  filter(Region == region, Year == year)
```

Render with params: quarto render report.qmd -P region:South

Common Issues & Solutions

YAML errors:

  • Check indentation (use spaces!)
  • Ensure colons have spaces after them
  • Validate YAML syntax

Rendering fails:

  • Check code chunk syntax
  • Look for missing packages
  • Review error messages carefully

Formatting issues:

  • Try clearing cache: quarto render --cache-refresh
  • Check for conflicting CSS/LaTeX

Tips for Success

  1. Start simple - Master basics before advanced features
  2. Use templates - Learn from existing examples
  3. Read error messages - They’re usually helpful!
  4. Experiment - Try new features in test documents
  5. Check the docs - Quarto documentation is excellent
  6. Join the community - Ask questions, share work
